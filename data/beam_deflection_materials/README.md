# Beam Deflection Material Source Archive

Ground-truth record for the 28 material rows in `js/beam_deflection/materials.js`.
This folder is what the September 2026 sign-off was actually checked against, so
that "reviewed: true" is a reproducible claim, not an assertion.

Ground truth hierarchy:

1. The governing standard or the manufacturer's own datasheet.
2. The publisher's current page for that document.
3. This archive, only as a convenience copy of what was read on the day.
4. `materials.js`, which must always agree with a row in `verified_values.csv`.

If this folder conflicts with the cited source, the source controls. If
`materials.js` conflicts with this folder, that is a bug in `materials.js`.

## Files

- `download_manifest.csv` - one row per source. Columns: `source_id`, `label`,
  `registry_url`, `expected_filename`, `access_type` (`open_pdf` / `open_html` /
  `paywalled`), `download_status` (`ok` / `not_downloaded`), `sha256`, `bytes`,
  `retrieved`, `notes`. The checksum is of the exact bytes that were read, so a
  re-download can be proved identical. Six of the thirteen sources are archived
  locally; the rest are paywalled standards, and their rows say so plainly
  instead of implying the standard was opened.
- `verified_values.csv` - 27 property values, each with the value as printed in
  its source, the unit it was printed in, the SI value stored in `materials.js`,
  the relative error between them, and the locator inside the document.
  Generated by `scripts/check-beam-material-sources.mjs`.
- `nds_table_4a_extract.csv` - all 25 Douglas Fir-Larch, Hem-Fir and
  Spruce-Pine-Fir rows from NDS Table 4A, extracted from the archived PDF. The
  PDF is not committed, so this is the durable record of what the table said.
  Includes the grades the tool does not ship, because the neighbouring rows are
  what let a reviewer confirm the right row was read.
- `sources/` - the PDFs themselves. Gitignored, per the convention in
  `data/.gitignore`.

## Re-running the check

    node scripts/check-beam-material-sources.mjs

It transcribes each source value, converts it to SI, and asserts `materials.js`
agrees within a stated tolerance. It exits non-zero on any disagreement, and
rewrites `verified_values.csv`. Reverting `alu-6061-t6` to its pre-review value
fails it at 14.4% off, which is the check working.

## Conventions

- **Filename:** `<publisher>_<document>_<topic>.pdf`.
- **Dual-designated standards use the metric designation.** ASTM A36/A36M reads
  "36 ksi [250 MPa]". 250 MPa is a designated value, not a conversion; deriving
  it from 36 ksi would give 248.2 MPa and manufacture a 0.7% disagreement that
  does not exist. Where a document is US-only, such as the Aluminum Design
  Manual, the stored value is a real conversion and carries a rounding
  tolerance instead.
- **A source row names the document that was read.** Several rows previously
  cited the ASM handbooks, which were never opened. If only a secondary summary
  was available, the manifest and the `source` field in `materials.js` say so.

## What this archive does not settle

- Paywalled standards (ASTM A36, A992, A240, the Aluminum Design Manual) were
  confirmed through secondary summaries only. Those values are widely and
  consistently reported, but nobody here has opened the standard.
- The NDS row is a third-party reproduction of Table 4A, not AWC's own PDF,
  which redirects to a landing page. Four grades were cross-checked against two
  independent sources before use, and the errata was checked for changes to
  these species (there are none).
- Six plastics rows rest on general published property tables, not a named
  resin datasheet. Grade-to-grade scatter for those polymers is wide, and
  the tool says so in its own warnings.
