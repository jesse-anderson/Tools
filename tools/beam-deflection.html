Results

Not a structural design tool. This is a teaching and first-pass estimating tool. It computes deflection, bending stress, moment, and reactions for an idealised prismatic beam. It does not check buckling, lateral-torsional stability, connections, fatigue, or any code requirement, and it must not be used to size a load-bearing member.

Independent check

Solve the same beam numerically, by assembling and solving Hermitian beam elements, and compare against every closed form the tool uses.

What this tool does not do

  • Euler-Bernoulli theory only. Shear deformation is neglected, which under-predicts deflection for short deep beams.
  • One load at a time. Superposition of several loads is left to you.
  • Full-span distributed loads only, no partial or triangular loads.
  • No buckling, no lateral-torsional stability, no connections, no fatigue, no code compliance.
  • Material properties are single representative values. All 28 rows were checked against the source cited on each one in September 2026, but a real member has scatter, and wood and plastics have a great deal of it.
